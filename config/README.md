# Environment configuration

`environment.example.json` is inert: null resource IDs, no recipients, CAPTURE mode, probe disabled. Make independent protected DEV and TEST copies. A label alone is not isolation. Their Sheets, evidence folders, secondary calendars, AppSheet apps, Script projects and connections must have distinct IDs and reviewed access. Production uses a separate protected configuration store/account/project, never a fallback or an entry in test allowlists. No PROD identifiers/template populated with real values belongs in Git. S01 guard deliberately rejects PROD entirely; production delivery is a later-stage implementation.

Use `config/private/` only for local access-controlled working copies; ignore rules are not encryption or an access control. Store company originals in restricted company storage. Keep credentials in provider-managed connections or the company's protected secret mechanism, never Sheets/source. For the S01 probe, Script Properties contain non-secret test IDs/allowlists, accessible only to trusted project editors. Do not place tokens/passwords there for this probe. Ben approves owner/editor membership; ordinary test users receive no source editing rights. Do not share the PROD credential store or production folders with DEV/TEST connection owners.

DEV and TEST permit synthetic records only. Test `.invalid` mailboxes are for local capture, never evidence of delivery. Replace only in protected integration configuration with verified direct test inboxes. PROD permits no test clock/recipient bypass; no production path is implemented here. External invoice/order/GHL/Phoenix actions have no adapter in S01.

Business timezone is Europe/London (not the workstation's timezone). Monday–Friday is the specification's configurable default. `holidayDates: null` means not supplied, not an approved empty holiday calendar. `capacitySettings: null` means unknown; no universal capacity is assumed. F0's empty holiday list is a later synthetic fixture, not company policy. No working-day scheduler exists until S03.
